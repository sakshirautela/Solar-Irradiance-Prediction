# ☀️ SolarPredict — Photovoltaic Irradiance & Yield Forecasting

> **Renewable energy machine learning regressor** forecasting solar irradiance ($W/m^2$) and photovoltaic power yield from meteorological parameters (Zenith angle, Humidity, Wind speed, Temperature).

---

## 📌 Methodologies

* **Temporal Preprocessing**: Lag features and rolling statistics preventing future lookahead bias.
* **Model Benchmarks**: Random Forest and XGBoost regressors achieving high $R^2$ correlation.
